# Reglas de Aplicación Visual:
1. **Fondos**: Usa predominantemente 'bg-aviva-onyx' o gradientes de 'from-aviva-wine' a 'black'.
2. **Textos**: Texto principal en 'text-aviva-bone' (no blanco puro). Títulos destacados en 'text-aviva-gold'.
3. **Acentos**: Botones y elementos de acción en 'bg-aviva-red' con bordes 'border-aviva-gold'.
4. **Sentimiento**: Todo componente debe sentirse pesado, lujoso y cinematográfico.
